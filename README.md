🎓 Student Placement Prediction Dashboard
📌 Description

This project is a Power BI dashboard developed to analyze student placement data and identify key factors affecting placement outcomes. It provides clear insights into placement trends, salary distribution, and student performance using interactive visualizations.

📊 Features
Placement trends analysis
Company-wise recruitment insights
Salary/package distribution
Branch-wise comparison
Impact of CGPA, backlogs, and skills

🛠️ Tools Used
Power BI
Excel / CSV Dataset

💡 Key Insights
Higher CGPA increases placement chances
Backlogs negatively impact placements
Hackathons and projects improve opportunities
Some branches have higher placement rates

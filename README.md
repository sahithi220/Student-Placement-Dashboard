✨ Overview

An interactive Power BI Dashboard designed to analyze and predict student placement outcomes.
This project transforms raw student data into powerful insights using dynamic visuals, helping understand placement trends, salary distribution, and skill impact.

💡 Key metrics displayed:

👨‍🎓 100K Students Analyzed
📊 CGPA Insights (749K+)

📁 300K+ Projects Evaluated

📈 Visual Insights:

Placement distribution analysis
Branch-wise performance comparison
Backlogs vs CGPA impact
